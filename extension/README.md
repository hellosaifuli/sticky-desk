# Sticky Desk for Chrome

The same board as the website, packed as a Chrome extension. Click the toolbar icon to open your board in a tab.

## Install it yourself (no store needed)

1. Unzip `sticky-desk-chrome.zip`.
2. Open `chrome://extensions` in Chrome.
3. Turn on **Developer mode** (top right).
4. Click **Load unpacked** and pick the unzipped `sticky-desk` folder.
5. Pin it from the puzzle-piece menu so the icon stays in the toolbar.

## Put it on the Chrome Web Store

Upload `sticky-desk-chrome.zip` at https://chrome.google.com/webstore/devconsole (one-time $5 developer fee).

## Your notes

The extension keeps its own copy of the board. Sign in with the same name and PIN as on your iPhone and iPad and they share one board.

Chrome on iPhone and iPad can't run extensions, so use the website there.
